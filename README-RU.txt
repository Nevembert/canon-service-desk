CANON SERVICE DESK 0.1.0
Бесплатное приложение с исходниками для Windows 10/11 x86/x64.
Неофициальный инструмент, не продукт Canon.

БЫСТРЫЙ ЗАПУСК
1. Полностью распакуйте архив в отдельную папку.
2. Подключите Canon через USB. Для чистой проверки закройте PrintHelp,
   Service Tool и окно состояния Canon.
3. Запустите CanonServiceDesk.exe. Установка приложения не нужна.
4. Автоматически начнётся проверка длительностью до 30 секунд.
5. Прочитайте вкладку «Диагностика». Нажмите «Сохранить отчёт ZIP»,
   если хотите передать результаты для разбора.

КНОПОЧНЫЙ СБРОС, О КОТОРОМ СООБЩИЛ ПОЛЬЗОВАТЕЛЬ G2411
После физической замены абсорбера и входа в сервисный режим:
  «Отмена» 5 раз, затем «Включение» 1 раз.
Пользователь сообщил, что это убрало ошибку на его G2411.
Это наблюдение одного владельца, не подтверждение для всех моделей/прошивок.
Инструкция есть на вкладке «Обслуживание». Приложение не нажимает кнопки
и не имитирует эту последовательность командами USB.

ЧТО РАБОТАЕТ В ВЕРСИИ 0.1
- Поиск подключённых PnP-устройств Canon, сведения о службе драйвера
  и кодах диспетчера устройств (включая 28: драйвер не установлен).
- Поиск интерфейсов USBPRINT и стандартное чтение IEEE 1284 Device ID.
- Логируются этап, код Windows, размер буфера, число полученных байтов,
  время запроса и фактический ответ в HEX.
- После CRC при чтении ID повторяется только это чтение меньшим буфером.
- Сканирование идёт в отдельном процессе. При зависании оно прерывается
  через 30 секунд; частичный отчёт и предыдущие операции остаются на диске.
- Объяснения с разграничением: факты измерения, возможная причина, действие.
- Отдельные расшифровки Service Tool 002/005/006/009 и ошибок Win32.
- Пробная страница с текстом и цветными полями через установленный драйвер.
  Она не является фирменным тестом дюз Canon.
- Открытие окна настроек драйвера: там доступны фирменные процедуры
  обслуживания, если установлена соответствующая версия драйвера Canon.
- Открытый журнал и экспорт ZIP; дополнительная запись обмена Service Tool.

ЛОГИ
Кнопка «Открыть логи» открывает текущий каталог:
  %LOCALAPPDATA%\CanonServiceDesk\Logs\дата_время_идентификатор

journal.txt      — подробный текстовый журнал, UTF-8.
events.jsonl     — структурированные события, по одному JSON на строку.
report.json      — устройства, очередь, ответы USB и ошибки сбора.
summary.txt      — выводы (создаётся при экспорте).
observation.txt  — введённое вами наблюдение (создаётся при экспорте).

Каждая новая проверка сохраняется отдельно. Старые логи не удаляются.
Приложение не отправляет данные в интернет. Для публикации или передачи
используйте экспортированный ZIP. В нём могут быть серийный номер и пути USB.
«Открытые логи» здесь означают читаемые файлы без пароля, доступные владельцу;
общедоступный сайт или внешняя телеметрия не создавались.

ЕСЛИ НУЖНО РАЗОБРАТЬ ОШИБКИ САМОЙ SERVICE TOOL
Папка trace содержит дополнительный наблюдатель, его исходники и инструкцию.
Он записывает API-обмен уже скачанной Service Tool без изменения её команд,
ответов и лицензии. Для него нужны Python 3.10+ и бесплатная Frida.
Основному EXE они не нужны. Анализатор выделяет, например, отказ в доступе,
занятое устройство и CRC при слишком большом буфере GET_1284_ID.
Сначала прочитайте trace\README-RU.txt.

ОГРАНИЧЕНИЯ
- Сброс EEPROM/абсорбера через USB и универсальные закрытые сервисные команды
  не реализованы. Приложение не выдаёт диагностику за выполненный сброс.
- Не изменяет регион, прошивку, серийный номер, драйвер или очередь заданий.
- Чтение ID не доказывает вход в сервисный режим и не проверяет печатающую
  головку. Режим нельзя надёжно вывести из одного имени Canon Device.
- Поиск очередей рассчитан на имена с Canon или G2010. Переименованная очередь
  может не отобразиться; физическое USB-устройство ищется отдельно.
- Сеть/Wi-Fi и Windows ARM пока не поддерживаются этой сборкой.
- Если драйвер отсутствует, код 28 относится к конкретному интерфейсу.
  Работа сервисного USB при этом может сохраняться.
- Нужен .NET Framework 4.7.2 или новее (обычно уже есть в Windows 10/11).
- EXE не подписан сертификатом разработчика. Защиту Windows отключать не нужно.
- Реальный USB-обмен и печать на вашем G2411 ещё не проверены разработчиком.
  Сведения о проведённых тестах находятся в VALIDATION.txt.

ИСХОДНИКИ И СБОРКА
src\Core.cs       — отчёт, журнал, разбор идентификатора и объяснения.
src\NativeUsb.cs  — SetupAPI, ConfigManager и стандартный USBPRINT IOCTL.
src\Program.cs    — интерфейс Windows Forms, отдельный процесс проверки, печать.
trace\            — наблюдатель Frida и анализатор Python.
tests\            — проверки парсера, выводов и наблюдателя.
build.cmd         — сборка EXE встроенным компилятором .NET Framework Windows.
