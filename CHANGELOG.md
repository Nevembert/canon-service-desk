# Изменения

## 0.2.0 — 2026-09-09

- Сервисный каталог и пошаговый мастер с записью результатов пользователя.
- Мастер сброса абсорбера G2411 по подтверждённой владельцем последовательности кнопок.
- Инструкции теста дюз, очисток, выравнивания, роликов, поддона, прокачки и сброса учёта чернил.
- История показаний Total / Print / Blank / TPAGE; сравнение и локальная отметка после обслуживания.
- Просмотр, приостановка, продолжение и удаление выбранного задания Windows с проверкой его идентичности.
- Опытная отправка BJL для теста дюз и обычной очистки через USBPRINT при явно заявленной поддержке BJL.
- Расширенный журнал и экспорт истории выбранного устройства.
- Проверка Windows spooler на изолированной очереди; снимки всех вкладок из собранного ZIP в CI.

Автоматический USB-сброс абсорбера G2411 и аппаратное обнуление Total / TPAGE ещё не реализованы.

## 0.1.0

Первая версия: PnP/USB-диагностика, объяснение ошибок, пробная печать, локальные логи и наблюдатель Service Tool.
