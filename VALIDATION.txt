Canon Service Desk 0.1.0 — проверка сборки, 2026-09-09

ПРОВЕРЕНО
- Сборка C# 5 в PE32 GUI / AnyCPU (.NET Framework) выполнена успешно.
- Компилятор: Mono C# compiler 6.8.0.105; предупреждения считаются ошибками.
- 22 теста C#: IEEE 1284 с префиксом/без префикса, пустой и усечённый ответ,
  чтение модели, разделение кодов Service Tool и Windows, частичный отчёт,
  одновременное наличие работающего USB и другого интерфейса без драйвера,
  JSON round trip, UTF-8 журнал, Windows quoting и размеры структур ABI.
- 7 тестов Python: выводы при ошибках открытия, большом/малом буфере с CRC,
  незавершённых запросах и ошибках самого наблюдателя.
- Проверка синтаксиса JavaScript (node --check).
- Тест JS-наблюдателя с имитацией Frida/Win32: фильтрация посторонних файлов,
  запрет преждевременного чтения асинхронного буфера, завершение запроса,
  сохранение реальных байтов, кода ошибки и очистка закрытых дескрипторов.
- GitHub Actions, Windows Server 2022 x64: сборка компилятором Microsoft
  .NET Framework с предупреждениями как ошибками; 22 теста C#, 7 тестов
  Python и тесты JS-наблюдателя успешно выполнены.
- На Windows успешно запущены в режиме --demo как свежая сборка, так и
  EXE из опубликованного CanonServiceDesk-v0.1.0-Windows.zip. Оба процесса
  создали снимок окна и завершились с кодом 0. Снимок основной вкладки
  опубликованного EXE просмотрен: русский текст и элементы управления видны.
  Эта проверка демонстрационных данных не обращается к USB-принтеру.

НЕ ПРОВЕРЕНО В ЭТОЙ СРЕДЕ
- Использование на Windows 10/11 с физическим устройством и вызовами
  SetupAPI/usbprint.sys: GitHub Actions проверял демо на Windows Server 2022.
- Реальный USB Canon G2411, физическая печать и окно его драйвера.
- Реальное внедрение наблюдателя Frida в Service Tool под Windows.
- Все вкладки и масштабы интерфейса: просмотрена только основная вкладка
  в демонстрационном запуске GitHub Actions.

СБРОС
Ни одного аппаратного сброса разработчик не выполнял. Реализации сброса
по USB в этой версии нет. Встроенная инструкция «Отмена 5 раз, Включение
1 раз после входа в сервисный режим» основана на сообщении владельца G2411.
Успешность ручного сброса отмечается только как user_report, не измерение.
