# Canon Service Desk

Бесплатное приложение для диагностики USB-принтеров Canon на Windows. Показывает состояние драйвера, ответы USB и понятный журнал операций. Исходный код доступен под лицензией MIT.

**Версия 0.2.0.** Сервисные процедуры, управление очередью и история счётчиков. Сброс абсорбера G2411 доступен как мастер ручной процедуры. Автоматический USB-сброс абсорбера и обнуление аппаратного Total / TPAGE пока не реализованы. Физические операции Canon разработчиком не проверены. Приложение не связано с Canon Inc.

## Скачать и запустить

**[Скачать Canon Service Desk 0.2.0 для Windows](downloads/CanonServiceDesk-v0.2.0-Windows.zip?raw=true)**

1. Распакуйте весь архив.
2. Подключите принтер через USB. Закройте другие программы, обращающиеся к принтеру, для чистой проверки.
3. Запустите `CanonServiceDesk.exe` — проверка начнётся автоматически.
4. Откройте результаты на вкладке «Диагностика». Для передачи результатов нажмите «Сохранить отчёт ZIP».

Основному приложению нужны Windows 10/11 x86/x64 и .NET Framework 4.7.2+. Python и платные ключи не нужны. Интерфейс на русском языке. EXE не подписан сертификатом разработчика.

Контрольная сумма архива: [SHA256SUMS.txt](downloads/SHA256SUMS.txt). Полная инструкция: [README-RU.txt](README-RU.txt).

## Возможности

| Возможность | Что делает версия 0.2 |
| --- | --- |
| Устройства и драйверы | Находит подключённые PnP-устройства Canon, показывает службу драйвера и коды Windows |
| Проверка USB | Читает стандартный IEEE 1284 Device ID через USBPRINT, сохраняет фактические байты ответа |
| Понятные ошибки | Разделяет коды Windows и Service Tool, объясняет возможные причины и следующий шаг |
| Обслуживание | Мастер сброса абсорбера, процедуры теста дюз, очисток, выравнивания, роликов и поддона; открытие Canon IJ через драйвер |
| Очередь печати | Список заданий, пауза, продолжение и удаление выбранного задания Windows |
| Счётчики | Импорт показаний, история и разница Total; локальная отметка после обслуживания |
| BJL · опытный | Прямой тест дюз и обычная очистка через USBPRINT при явно объявленной поддержке BJL |
| Открытые логи | Показывает журнал, сохраняет TXT/JSONL/JSON и экспортирует ZIP |
| Запись Service Tool | Дополнительный наблюдатель фиксирует обмен утилиты с Canon для разбора 005/006 |

Сканирование выполняется в отдельном процессе с ограничением 30 секунд. Частичный отчёт сохраняется при зависании. Успешное чтение USB не выдаётся за подтверждение сервисного режима или успешного сброса.

## Сброс абсорбера

После физического обслуживания абсорбера и входа в сервисный режим:

1. Нажать **«Отмена» 5 раз**.
2. Нажать **«Включение» 1 раз**.

Владелец сообщил, что эта последовательность убрала ошибку на его G2411. Это наблюдение одного устройства, а не гарантия для всех Canon и прошивок. Кнопки нажимаются на принтере; приложение не имитирует их командами USB. Пошаговый мастер встроен во вкладку «Обслуживание».

[Матрица поддержки, ограничения и источники процедур](docs/SERVICE-SUPPORT.md). «Начать отсчёт после обслуживания» на вкладке «Счётчики» создаёт локальную отметку приложения: общий пробег принтера остаётся прежним.

## Журнал и приватность

Логи сохраняются в `%LOCALAPPDATA%\CanonServiceDesk\Logs`, история — в `%LOCALAPPDATA%\CanonServiceDesk\History`. Автоматической отправки в интернет нет.

Отчёт может содержать серийный номер принтера, путь USB, названия документов/пользователей в очереди, историю и введённое пользователем наблюдение. Перед размещением в публичном issue просмотрите и удалите личные данные. Настоящие пользовательские логи в этот репозиторий не входят.

Чтобы исследовать ошибку самой Service Tool, используйте [инструкцию наблюдателя](trace/README-RU.txt). Этому дополнительному инструменту нужны Python 3.10+ и Frida. Он не меняет команды, ответы, файл EXE или проверку лицензии. Захват WinUSB, IOCP и обмен через другие процессы пока не поддерживаются.

## Сборка и тесты

На Windows запустите `build.cmd` — используется компилятор .NET Framework. Для C# тестов есть `tests/run_tests.cmd`.

Дополнительные тесты:

```sh
python -m unittest discover -s tests -p "test_*.py" -v
node tests/test_observer.js
```

Проверки и ограничения: [VALIDATION.txt](VALIDATION.txt). Workflow `Windows build and test` собирает программу, выполняет тесты, проверяет управление изолированной очередью Windows, упаковывает ZIP и создаёт снимки всех вкладок в демо. Физический принтер в CI не используется. Результат конкретной сборки доступен во вкладке Actions.

## English

An early, free Windows diagnostic utility for Canon USB printers, with Russian UI and readable local logs. Includes guided G2411 maintenance, a manual absorber-reset wizard, print queue controls, counter history, experimental advertised-BJL commands, and an optional Frida observer for Canon Service Tool I/O. **Automatic USB waste-ink and hardware lifetime page counter resets are not implemented.** The published binary has not yet been hardware-tested by the developer. Source is MIT-licensed; not affiliated with Canon.
